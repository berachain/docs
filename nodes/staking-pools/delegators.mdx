---
title: "Delegation Guide"
description: "Use Foundation-delegated capital to run a staking pool: form the handler, then land the pool."
---

Delegated staking pools have two phases:

1. **Form** — `delegator-delegate.sh` deploys and funds the `DelegationHandler`, runs `delegate()`, and grants `VALIDATOR_ADMIN_ROLE`.
2. **Land** — `install.sh` creates the pool with delegated funds, activates, and optionally deposits the remainder.

## 1. Form the handler

From `guides/apps/staking-pools/install-helpers/` on a machine with RPC access (not the validator):

```bash
export EL_RPC_URL=https://bepolia.rpc.berachain.com
./delegator-delegate.sh
```

The script prompts for pubkey, delegate amount, and validator-admin address. Set `VALIDATOR_PUBKEY`, `DELEGATE_AMOUNT_BERA`, and `VALIDATOR_ADMIN` in `env.sh` to pre-fill those prompts, or pass `--pubkey`, `--amount`, and `--validator-admin` to skip them.

The script prints each `cast send` (or runs it when `PRIVATE_KEY` is set). Steps 3–4 (`delegate`, `grantRole`) require `DEFAULT_ADMIN_ROLE` on the handler — often the Foundation Safe.

## 2. Land the pool (operator)

From `guides/apps/staking-pools/install-helpers/` (same directory as `delegator-delegate.sh`):

```bash
export EL_RPC_URL=https://bepolia.rpc.berachain.com
export CL_NODE_API_URL=http://127.0.0.1:3500
./install.sh
```

When a formed handler with delegated funds exists for your pubkey, `install.sh` lands the pool automatically. See [Installation](/nodes/staking-pools/installation).
