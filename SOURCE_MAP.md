# Documentation source map

Use this map before writing or reviewing a behavior claim. The existing page is not evidence that its claim is correct.

Repository names ending in `/` refer to verified local checkouts. Their filesystem roots vary by environment. Repositories named as `berachain/<name>` may require a GitHub lookup or a local clone.

## Rules

- Read the implementation before stating behavior. Interfaces define events and errors, but implementation wins when comments disagree.
- Confirm every named function, event, error, role, and constant with `rg` in its owning repository.
- A page can cross repository boundaries. Follow every contract in the interaction instead of stopping at the repository mapped to the page.
- You may read `*-internal` repositories for truth. Never link them from published pages or publish information that is not already public.
- Link published application binary interfaces (ABIs) to `github.com/berachain/abis/blob/main`. If the published ABI lacks a symbol the docs need, update `abis` first and wait for that change before documenting the symbol.
